Pergunta 5 (4 pontos) 
Note que na tabela de estabelecimentos há duas colunas: TIPO_LOGRADOURO e LOGRADOURO. O TIPO_LOGRADOURO pode ser, por exemplo, “RUA” ou “AVENIDA”. Neste esquema de dados, o LOGRADOURO deve conter apenas o nome da rua ou avenida, por exemplo, “AFONSO PENA”, e não “AVENIDA AFONSO PENA”. 

Você quer checar a qualidade dos dados e determinar em quantos estabelecimentos o LOGRADOURO contém “AVENIDA”, o que está incorreto e deve ser corrigido.

Dica: em muitos casos, as UDFs (funções definidas pelo usuário) são uma forma muito conveniente de implementar uma lógica dentro de uma função python e chamá-la dentro de uma consulta SQL. Vamos fazer isso para computar quantos estabelecimento tem um logradouro cujo endereço é uma AVENIDA.

Crie uma função em Python “def is_avenida(logradouro):” que recebe um logradouro e decide se ele é uma avenida ou não. Dica: Use startswith() e fique atento ao resultado da questão anterior, pois ele pode impactar a lógica da sua função. Esteja atento a maiúsculas e minúsculas.

Em seguida, use Spark SQL para executar uma consulta como "SELECT COUNT(*) FROM estabelecimentos WHERE is_avenida(LOGRADOURO) == True” para contar quantos estabelecimentos ficam localizados em uma avenida.

Opções da pergunta 5:

0

52.587

219.837

20.944.157

**Resposta:** 52.587

Pergunta 15 (4 pontos) 
 Você está considerando armazenar os dados de estabelecimentos para fins de processamento analítico, e está considerando um data lake ou data warehouse como tecnologia de armazenamento.  Qual das seguintes afirmações melhor descreve a diferença fundamental entre um Data Lake e um Data Warehouse?
Opções da pergunta 15:

Um Data Lake é usado apenas por cientistas de dados, enquanto um Data Warehouse é usado exclusivamente por analistas de negócios.

Um Data Lake é um repositório de dados bruto e não estruturado, enquanto um Data Warehouse é projetado para armazenar dados estruturados e semânticos.

Um Data Lake é uma solução de armazenamento de dados on-premises, enquanto um Data Warehouse é baseado em nuvem.

Um Data Warehouse é mais adequado para armazenar todos os tipos de dados brutos, incluindo dados não estruturados, enquanto um Data Lake é projetado para dados altamente estruturados.

**Resposta:** Um Data Lake é um repositório de dados bruto e não estruturado, enquanto um Data Warehouse é projetado para armazenar dados estruturados e semânticos.
